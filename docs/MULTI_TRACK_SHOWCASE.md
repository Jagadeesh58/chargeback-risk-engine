# Multi-track showcase modules

The main submission remains focused on **Track 02 — AI Risk Manager**. The optional modules in `extensions/` demonstrate how the same safety primitives transfer to the other Razorpay Buildathon problem shapes without changing the Track 02 decision path.

- Agentic commerce: structured proposal -> consent/capability gate -> bounded action.
- Revenue recovery: expected-recovery scoring -> bounded intervention plan -> explicit no-action option.
- Finance controller: deterministic match scoring -> confidence threshold -> exception queue.

These are demonstration modules, not claims that one submission should enter multiple tracks at once.
